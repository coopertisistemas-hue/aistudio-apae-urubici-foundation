# Core User Journeys

## Learn about APAE
Home → institutional summary → area/project → evidence/story → contact or support CTA.

## Donate once
Home/how-to-help → donation → amount → payment method → confirmation → thank-you email → optional relationship consent.

## Become a recurring supporter
Donation → recurring option → provider authorization → confirmation → Admin recurrence visibility → ongoing relationship if consented.

## Become a partner
Home/partners/how-to-help → partnership information → interest form → Admin relationship queue → human follow-up.

## Volunteer
How to help → volunteer form → consent → Admin review → human contact.

## Submit testimonial
Public testimonial page or invitation link → form → consent choices → Supabase pending record → Admin moderation → approved publication.

## Read Inclusion & Human Development
Home editorial block → selected Portal content → article/source → optional related APAE content.

## Publish APAE news
Admin draft → media/content → validation → preview → publish → public site → optional Portal/social distribution workflow.

## Update Home hero
Admin → select mobile/desktop media → edit copy/CTAs/overlay → preview → publish → site receives managed configuration.
