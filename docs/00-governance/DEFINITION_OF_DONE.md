# Definition of Done

A feature is not done because it renders.

## Product
- Foundation requirement satisfied.
- No unauthorized scope expansion.
- No fabricated institutional content.
- Mobile and desktop behavior defined.

## UX/UI
- Mobile-first behavior verified.
- Desktop intentionally composed.
- Loading, empty, error, success and validation states covered.
- Accessibility requirements satisfied.
- Visual quality meets premium acceptance criteria.

## Data
- Data ownership defined.
- Admin-managed fields are not hardcoded.
- Consent and privacy rules applied.
- Security boundaries respected.

## Engineering
- Build/type/lint/tests pass where applicable.
- No privileged secrets exposed to clients.
- Error handling and graceful fallbacks implemented.
- Observability/logging adequate for production-impacting flows.

## Release
- Smoke tests complete.
- Production configuration verified.
- Critical integrations tested.
- Release evidence recorded.
- Production explicitly certified.
