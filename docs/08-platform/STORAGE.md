# Storage

## Repository assets
Use Git for stable design/brand assets and selected approved hero media that must ship with the application.

## Managed storage
Use object storage for:
- editorial uploads;
- galleries;
- testimonial photos;
- partner logos uploaded operationally;
- transparency documents;
- dynamic hero assets when Admin-managed.

## Metadata
Track where relevant:
- file type;
- size;
- dimensions/duration;
- source;
- rights/consent state;
- uploaded_by;
- created_at;
- usage category.

## Security
Separate public and private buckets/paths by purpose. Signed access should be used when public exposure is not appropriate.
