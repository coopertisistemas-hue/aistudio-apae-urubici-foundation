# Social Media Module

## Phase 1
- official social links;
- share actions;
- optional curated embeds only if performance/privacy are acceptable.

## Phase 2
Admin content can become distribution-ready:
- Instagram candidate
- Facebook candidate
- newsletter candidate

AI may assist with channel-specific draft copy in the future, but publication remains governed.

## Rule
The website is a source of canonical institutional content; social networks are distribution channels, not the sole repository of institutional knowledge.
