# Partners Module

## Home placement

Partners should appear as a premium section close to the end of the Home, before the final footer area.

## Purpose

Provide institutional recognition without turning APAE into an advertising surface.

## Suggested fields

- name
- logo
- category
- short_description
- website
- instagram
- portal_profile_url
- supported_projects
- featured
- display_order
- partnership_start
- partnership_end
- status

## Presentation

Prefer a calm and elegant logo presentation with optional featured-partner storytelling and a link to a full Partners page.
