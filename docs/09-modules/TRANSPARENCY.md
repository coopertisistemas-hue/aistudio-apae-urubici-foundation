# Transparency Module

## Content types
- statute;
- leadership information;
- annual reports;
- financial statements;
- agreements/convênios;
- accountability documents;
- certificates;
- institutional policies.

## Fields
- title
- category
- year/period
- description
- file
- status
- publication date

## UX
Users must be able to filter/browse without navigating an unstructured file dump.

## Governance
Only documents approved for public disclosure may be published.
