# Campaigns

## Purpose
Support time-bound or ongoing institutional fundraising/community initiatives.

## Suggested fields
- title
- slug
- summary
- story/body
- cover media
- goal amount where appropriate
- raised amount derived from confirmed donations where enabled
- start/end dates
- status
- CTA
- associated project
- featured flag

## Rules
- financial progress must derive from trusted confirmed payment data when displayed;
- campaign claims must be institutionally validated;
- expired campaigns should not remain promoted unintentionally.
