# Performance Gates

## Priorities
Mobile performance and media discipline.

## Verify
- optimized hero media;
- responsive images;
- lazy loading where appropriate;
- no unnecessary third-party scripts;
- stable layout;
- sensible font loading;
- fast first meaningful content;
- cached static assets;
- external embeds isolated/lazy where possible.

## Recommended budgets
Objective targets to confirm at implementation (industry-standard Core Web Vitals, "good" thresholds), measured on representative mobile conditions:
- LCP ≤ 2.5s;
- INP ≤ 200ms;
- CLS ≤ 0.1.

These are standard reference thresholds, not institutional data. Final budgets are confirmed during implementation waves.

## Principle
Premium visual quality may not be purchased through unacceptable mobile performance.
