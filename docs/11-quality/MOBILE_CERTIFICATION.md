# Mobile Certification

Mobile is P0.

## Must verify
- primary navigation;
- hero/video/poster;
- Home section hierarchy;
- donation flow;
- contact/volunteer/partner forms;
- testimonial submission;
- article reading;
- document access;
- Admin common urgent actions;
- touch targets;
- keyboard appearance/input types;
- viewport/reflow;
- image/video performance.

## Network
Review key public journeys under realistic mobile network conditions, not only local broadband.

## Failure
A release with materially broken or second-class mobile UX cannot be certified.
