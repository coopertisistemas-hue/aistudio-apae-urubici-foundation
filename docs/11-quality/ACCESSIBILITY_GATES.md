# Accessibility Gates

## Automated
Run automated accessibility tooling on representative pages.

## Manual
- keyboard-only navigation;
- visible focus;
- mobile zoom/reflow;
- form labels/errors;
- semantic headings/landmarks;
- alt text review;
- video alternatives;
- reduced motion;
- screen-reader spot checks on critical journeys.

## Critical journeys
- Home navigation
- donation
- contact
- testimonial form
- article/news
- transparency documents
- Admin login and key forms

## Certification
Known critical WCAG blockers prevent production certification.
