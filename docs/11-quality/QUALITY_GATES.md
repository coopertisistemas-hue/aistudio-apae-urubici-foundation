# Quality Gates

A release is not certified only because it exists on `main`.

## Mandatory gates

- Foundation compliance
- Mobile-first review
- Desktop premium review
- Accessibility review
- Responsive review
- Content integrity
- No fabricated institutional data
- Form validation
- Error/empty/loading states
- Security review
- Data/consent governance review
- Performance review
- Production smoke test
- Production certification

## Readdy rule

Readdy works on `main`, but `main` does not automatically mean production-certified.

Production promotion/certification remains an explicit delivery gate.
