# SEO and AEO

## Technical
- semantic pages;
- clean URLs;
- canonical URLs;
- XML sitemap;
- robots rules;
- metadata;
- Open Graph;
- structured data where appropriate;
- performant responsive media.

## Editorial
- clear page intent;
- descriptive headings;
- concise summaries;
- entity clarity;
- local context;
- answerable factual sections;
- source attribution.

## Local discovery
Maintain validated institution name, address, contact and social links consistently.

## AI answer readiness
Prefer clear factual blocks, definitions, FAQs and well-structured institutional information over keyword stuffing.

## Rule
SEO must never justify fabricated statistics or low-value content.


## Proposal/staging indexing rule

Any publicly reachable W01P proposal/staging deployment must use `noindex, nofollow` until it is explicitly promoted to official production.

Before removing noindex:
- institutional content must be validated;
- canonical production domain must be known;
- production metadata must be approved;
- social preview media must be approved;
- multilingual hreflang/canonical behavior must be validated.

Do not invest in final multilingual SEO for placeholder/proposal content.
