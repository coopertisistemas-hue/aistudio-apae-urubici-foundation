# Meta / Instagram / Facebook

## Objectives
- maintain official account links;
- support future governed content distribution;
- optionally surface selected social content on Site.

## Integration principles
- external platform outages must not break core Site content;
- tokens/secrets remain server-side;
- permissions must be minimal;
- publishing automation requires explicit institutional approval;
- API terms/capabilities must be revalidated before implementation.

## Content
Canonical long-form institutional content should remain owned by APAE Site/Admin even when distributed to social networks.
