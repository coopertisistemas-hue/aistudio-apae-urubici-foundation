# Accessibility

Accessibility is P0 and intrinsic to the institution's mission.

## Baseline
Target WCAG 2.2 AA behavior wherever applicable.

## Requirements
- semantic HTML;
- keyboard operability;
- visible focus;
- sufficient contrast;
- scalable text;
- accessible names;
- form labels and errors;
- useful alt text;
- captions/transcripts where appropriate;
- touch targets suitable for mobile;
- reflow without loss of content;
- orientation flexibility;
- reduced-motion support;
- no color-only meaning.

## Content
Avoid patronizing, infantilizing or sensational language about disability.

## Testing
Automated checks are necessary but not sufficient. Key journeys require manual keyboard/mobile review.
