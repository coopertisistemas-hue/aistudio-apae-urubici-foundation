# Mobile-First Contract

## Priority

Mobile is the primary product experience and a P0 requirement.

Desktop is also a fully designed premium experience.

## Mobile requirements

- Thumb-friendly navigation.
- Large and consistent touch targets.
- Short, understandable forms.
- Correct mobile input types.
- Fast donation flow.
- Mobile-specific hero media.
- Responsive imagery.
- Performance-conscious media loading.
- Reduced-motion fallback.
- Accessible contrast.
- Keyboard and assistive technology support.
- No critical information dependent only on color.

## Hero media

The content model must support:
- desktop video;
- mobile video;
- desktop poster;
- mobile poster;
- reduced-motion fallback;
- headline;
- subheadline;
- primary CTA;
- secondary CTA;
- overlay/opacity;
- publication state.

Media should be replaceable through Admin when designated as dynamic content.
