# Premium UX Acceptance

A screen is not premium because it is visually polished.

## Public Site acceptance
- clear first-screen purpose;
- excellent mobile composition;
- intentional desktop composition;
- strong content hierarchy;
- high-quality media treatment;
- restrained visual effects;
- readable long-form content;
- clear CTAs;
- fast perceived performance;
- trustworthy forms;
- graceful empty/failure states.

## Admin acceptance
- low training burden;
- clear terminology;
- safe publishing;
- fast common tasks;
- useful defaults;
- preview where needed;
- visible save/publish feedback;
- reversible or confirmable destructive actions;
- mobile support for common urgent actions.

## Rejection criteria
- generic template feel;
- overcrowded Home;
- arbitrary gradients/colors/fonts;
- inaccessible contrast;
- unexplained icons;
- broken mobile hierarchy;
- CRUD-only Admin experience.
