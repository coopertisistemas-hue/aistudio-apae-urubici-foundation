# Forms

## General
- Ask only for data needed for the stated purpose.
- Use short mobile-friendly flows.
- Use correct input types/autocomplete.
- Show validation near the field.
- Preserve entered data after recoverable errors.
- Explain why sensitive fields are requested.
- Provide explicit success state and next step.

## Marketing consent
Optional relationship/marketing consent must be separate from service/payment submission.

## Testimonial
Consent choices must be explicit and granular.

## Donation
Do not add unnecessary friction before payment.
Relationship opt-in may follow confirmation but must remain optional.

## Volunteer/partner/contact
Capture source, consent and follow-up status where useful for CRM.

## Anti-abuse
Public forms should support appropriate bot/spam protection without creating unreasonable accessibility barriers.
