# Spacing and Grid

## Principles
- Mobile-first 4/8-point rhythm.
- Consistent vertical spacing.
- Generous whitespace as a premium signal.
- Avoid dense card walls.
- Content width optimized for readability.
- Desktop uses intentional columns, not stretched mobile stacks.

## Provisional scale
Use a coherent token scale derived from multiples of 4/8. Exact implementation tokens must be frozen before visual certification.

## Breakpoint behavior
Breakpoints should follow content needs, not device-brand assumptions.

## Long-form
Article text should maintain comfortable measure and line-height; media can break the text column intentionally when appropriate.
