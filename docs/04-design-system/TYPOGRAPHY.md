# Typography

Status: W01P PROPOSAL STANDARD — final W02 approval remains required.

## Proposal pairing

Use:

- Headings / editorial emphasis: **Fraunces**
- Body / navigation / interface: **Manrope**

This pairing is currently preferred because it combines editorial warmth with contemporary readability and supports the desired premium, human and institutional character.

## Requirements

- Excellent legibility on small screens.
- Strong editorial hierarchy.
- Comfortable long-form reading.
- Clear interface labels and controls.
- Responsive type scaling.
- Accessible minimum sizes and line heights.
- Efficient web-loading strategy.

## Rule

Readdy and other implementation agents should use Fraunces + Manrope during W01P unless an explicit Foundation update changes the proposal standard.

Final production certification still requires W02/institutional approval.
