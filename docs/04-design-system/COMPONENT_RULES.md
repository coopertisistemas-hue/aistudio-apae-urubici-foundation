# Component Rules

## Required component families
- Header/navigation
- Hero
- Section header
- Content card
- Project/campaign card
- Article/news card
- Event card
- Testimonial card
- Partner logo/item
- Impact metric
- CTA band
- Donation selector
- Form controls
- Modal/dialog
- Toast/feedback
- Pagination/load-more
- Empty/error/loading states
- Document list
- Media gallery

## Premium rules
- Consistent radii, spacing and typography.
- Restrained shadows.
- Clear interactive states.
- No decorative animation that competes with content.
- Cards must have purposeful hierarchy, not identical template repetition.
- Components must define mobile and desktop behavior.

## Admin
Admin shares the design system but may use denser operational variants.
