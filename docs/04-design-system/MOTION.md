# Motion

## Principle
Motion supports comprehension and warmth; it does not exist to impress.

## Rules
- Prefer subtle transitions.
- Respect `prefers-reduced-motion`.
- Avoid scroll-jacking.
- Avoid excessive parallax.
- Hero video must have static fallback.
- Loading indicators should be calm and clear.
- Admin actions should prioritize immediate feedback over animation.

## Prohibited
- autoplay audio;
- flashing content;
- motion essential to understanding without alternative;
- decorative reveal patterns that delay access to content.
