# Color System

Status: PROVISIONAL — requires brand validation and final visual exploration.

## Direction

Use APAE institutional identity as the anchor, complemented by:
- refined light neutrals;
- dark text neutrals;
- restrained supportive accents;
- accessible functional colors.

## Rules

- Do not invent arbitrary colors in implementation.
- Maintain sufficient contrast.
- Avoid saturating the interface with institutional blue.
- Functional states must be consistent across Site and Admin.
- Final tokens must be approved before design implementation is considered certified.
